# Project Documentation

This directory contains supporting documentation for Open-Sesame AndroidNative Lite.

## Index

- `ARCHITECTURE.md`: code structure, main runtime flow, and module responsibilities.
- `PRODUCT_PRINCIPLES.md`: product direction, UI hierarchy, interaction rules, and privacy boundaries.
- `RELEASE.md`: versioning, signing, verification, screenshot, push, and GitHub Release checklist.
- `release-notes/`: longer historical release notes when README would become too large.
- `images/`: README and release screenshots. Screenshots must not expose real door names or real license plates.

## Documentation Rule

The README should explain what the app is, how to build it, and where to download it. Detailed process notes belong in this directory.
