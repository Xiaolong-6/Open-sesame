# Open-Sesame Android Native Lite v0.5.8

## Summary

`v0.5.8` is the first signed release build after the native Android Lite UI refresh.

## User-Facing Changes

- Reworked the main screen around one-tap door opening.
- Replaced the earlier step-based flow with focused Door, Vehicle, Open, and Status areas.
- Added direct empty-state actions for scanning a new door and adding a license plate.
- Added centered Door and Vehicle picker dialogs.
- Added long-press selection mode for editing one saved item or deleting selected items.
- Added a full-screen Settings screen.
- Added release-page QR code sharing and Android share-sheet link sharing.
- Added English, Finnish, and Chinese localization resources.
- Added System, Light, and Dark theme preferences.
- Added About release/update status.

## Developer-Facing Changes

- Split the native Android code into smaller modules around UI, dialogs, profiles, sharing, themes, locale, updates, and opener logic.
- Centralized release metadata in `ReleaseInfo`.
- Added docs for architecture, product principles, release process, and future agent handoff.
- Sanitized archived documentation so historical files do not expose a specific door location.

## Install Note

If a previous build was installed with a debug or test signing key, Android will reject an in-place update to this signed release. Uninstall the older package before installing this APK. Future releases signed with the same release keystore can update normally.
